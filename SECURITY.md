# Security Policy

## Scope

This repository contains the QuietForge profile index and documentation only. Do not
include credentials, tenant data, client records or internal operational details in
issues, pull requests or discussions.

## Reporting

Report a suspected vulnerability privately to `quietforge@flexgrafik.nl`. Include the
affected file or URL, reproduction steps and impact. Do not publish sensitive details
before a fix or mitigation is agreed.

## Public proof boundary

Repository visibility does not grant a licence or permission to reuse private QuietForge
frameworks, tenant code or client data.
